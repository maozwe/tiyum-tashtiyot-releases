# תיאום תשתיות – התקנה

לוח עבודה מקומי לפורטל תיאום התשתיות הלאומי. הלוח רץ על המחשב שלך, וההתחברות לפורטל נשארת אצלך.

## התקנה

1. הורד את `tiyum-tashtiyot-setup.exe` מ-[הגרסה האחרונה](../../releases/latest).
2. הפעל אותו. אם Windows מציג "Windows protected your PC", לחץ **More info** ואז **Run anyway** (הקובץ לא חתום דיגיטלית).
3. ההתקנה מורידה את מה שצריך (נדרש אינטרנט, בפעם הראשונה כמה דקות), יוצרת קיצור דרך "תיאום תשתיות" בשולחן העבודה ופותחת את הלוח.
4. בלוח: לשונית **מערכת** ← **התחבר מחדש (SMS)**, ואז בחר תיקיית מסמכים בלשונית **תיקים**.

## עדכונים

מחשב שכבר מותקן בודק כאן אם יש גרסה חדשה. כשיש, מופיע פס עדכון בראש הלוח, ובלשונית **מערכת** כפתור "עדכן". העדכון שומר את ההתחברות וההגדרות.

## מה יש בקובץ

רק קוד התוכנה. אין בו פרטי התחברות, נתונים מהפורטל או מסמכים.

דרישות: Windows 10/11, ו-Google Chrome או Microsoft Edge.
